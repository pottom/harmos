Two ways to dress a password bench

The engine is done; this decides how it looks. Every screen below is drawn against the real vault's shape — ~10k entries, folders eight deep, titles up to 123 columns, duplicate names, accents everywhere. Same data, two treatments. Pick, and theming becomes free.

Decision 1

Default theme

Brass (locksmith's bench) or charm (the stock Charm purple/pink). This is the one that matters.

Decision 2

Breakpoints

Where the layout switches from two-pane to push/pop to compact. Starting guesses shown; adjust to the content.

Decision 3

Column-drop order

What falls away as the terminal narrows. Title and the source badge never drop.

Decision 1 — the two themes, same screen

browsing · search “admin” · ≥100 cols · two-pane

Six admin hits across four sources — the case where copying the wrong one is the worst thing the program can do. Watch what carries the meaning: in brass, amber is spent only on the secret and the selected row, so the source badge and the countdown read instantly. In charm, the purple selection and the pink countdown gradient compete with each other and with everything else.

Decision 2 — the breakpoint ladder

brass · same search, four widths

Narrow isn't a squashed wide — it's a different interaction. At 60–99 the detail pane leaves and → navigates into an entry. At 40–59 columns drop from the right. Under 40×10 it refuses rather than garbles. The source badge never drops — provenance outranks aesthetics.

The one bold thing — the clipboard countdown

the only place the interface shows a secret's real lifetime

When you copy, a depleting brass bar shows the seconds before the value is wiped. Spend the boldness here; keep everything else quiet. It takes available width, and degrades to a bare 28s when there's no room for a bar.
